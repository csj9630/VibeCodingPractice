# sub-ocr-2026

2026-07-31 ~ 2026-08-07 진행한 서브 프로젝트.
OCR 및 LLM를 활용한 문서정리 Web Service.

## 프로젝트 구조

```
sub-ocr-2026/
├── frontend/    # React (Vite) 기반 프론트엔드
├── backend/     # FastAPI 기반 백엔드
└── storage/     # 이미지 업로드 및 결과물 임시 저장소
```

## 실행 방법 (Docker Compose)

```bash
docker-compose up --build
```
